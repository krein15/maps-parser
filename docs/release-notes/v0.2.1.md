Версия-поправка: 2ГИС перестал обрывать выдачу, и программа теперь этим пользуется.

## Выдача 2ГИС листается до конца

До ноября выдача 2ГИС заканчивалась на пятой странице, то есть на 60 организациях. Чтобы собрать больше,
программа резала город на участки по карте и обходила каждый отдельно. 5 ноября недельная проверка формата
заметила, что шестая страница пришла как шестая. Проверили вживую: «магазин» по Тюмени листается до последней,
203-й страницы (2436 мест), по Екатеринбургу — дальше трёхсотой.

Теперь сбор идёт одним листанием, страница за страницей, пока не наберётся нужное число фирм или не кончится
выдача. Эталон тот же, что и раньше: 600 «магазинов» по Екатеринбургу — **600 уникальных организаций
за 50 запросов** вместо 59 и без единого участка. Фирмы идут в том порядке, в каком их видит посетитель
2ГИС, а «нет в 2ГИС» опирается на выдачу, просмотренную целиком.

## Если потолок вернётся

Участки никуда не делись, они стали запасным путём. Если 2ГИС снова начнёт возвращать первую страницу вместо
следующей, программа заметит это сама, запомнит, сколько страниц ей отдали, и по этому числу разрежет город.
Недельная проверка формата теперь следит именно за этим.

## Честнее на длинной выдаче

- Страница без новых организаций больше не считается концом выдачи: в глубине попадаются страницы из одних
  домов и улиц. Концом считаются три такие страницы подряд или последняя страница выдачи.
- Если страница выдачи не открылась из-за сети, источник не помечается как «показал всё»: иначе «нет в 2ГИС»
  досталось бы фирмам, до которых сбор просто не дошёл.
- При сборе участками «показал всё» пишется, только если каждый участок долистан до конца.

## Проверено

222 теста без сети, семь живых проверок формата обеих карт, сквозной сбор «кофейня» по Тюмени: 2ГИС отдал
84 организации при старом потолке в 60, отчёт записан.

## Как запустить

Скачайте архив, распакуйте целиком и запустите `MapsParser.exe`. Python не нужен. Windows может
предупредить о неизвестном издателе — у программы нет платной подписи разработчика; «Подробнее» →
«Выполнить в любом случае».

Отчёты складываются в «Документы\Карты Парсер».
